Lifecycle Hooks in Vue 3

I lifecycle hooks sono dei momenti precisi nella vita di un componente, in cui puoi eseguire del codice. Ecco i principali:

  1. setup() :
    • È il primo che viene eseguito, prima del mount. Qui definisci lo stato reattivo, le funzioni e i composables.
  2. beforeMount :
    • Si esegue prima che il componente venga montato sul DOM.
  3. mounted :
    • Si esegue dopo il montaggio del componente. È il momento ideale per fare interazioni con il DOM o chiamate API.
  4. beforeUpdate :
    • Si esegue prima che il DOM venga aggiornato, utile per operazioni di preparazione.
  5. updated :
    • Si esegue dopo che il DOM è stato aggiornato. Perfetto per verificare gli aggiornamenti.
  6. beforeUnmount :
    • Si esegue subito prima che il componente venga rimosso dal DOM.
  7. unmounted :
    • Si esegue dopo che il componente è stato rimosso, ideale per la pulizia (es. rimuovere event listener).
Composition API

La Composition API è un approccio introdotto in Vue 3 per organizzare la logica dei componenti in modo più flessibile e riutilizzabile. Invece di separare il codice per categorie (data, methods, computed), la Composition API ti permette di raggruppare la logica in funzioni chiamate composables . Questo rende il codice più modulare, più facile da mantenere e da testare, soprattutto in componenti complessi.

In realtà, TypeScript permette di gestire i parametri con tipi uniti, quindi, per esempio, una funzione può accettare sia un string che un number grazie all'uso delle union types . Ad esempio:

function example(value: string | number): string {
  if (typeof value === 'string') {
    return `String: ${value}`;
  } else {
    return `Number: ${value}`;
  }
}

In questo modo, TypeScript ti consente di gestire i diversi tipi di parametri in modo sicuro. L'uso di any è sconsigliato perché disabilita la tipizzazione, mentre con le union types mantieni il controllo sui tipi. Ottimo lavoro!
