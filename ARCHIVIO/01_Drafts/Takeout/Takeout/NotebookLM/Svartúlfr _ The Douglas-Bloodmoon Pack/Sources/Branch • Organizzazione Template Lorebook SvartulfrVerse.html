  • Cosa fanno World/Scenario: Traducono il flag per l'LLM. Ad esempio, il World_Template Sci-Fi dirà all'LLM: "Se 0x0A è attivo, i propulsori dell'astronave sono rotti" . Il World_Template Fantasy dirà: "Se 0x0A è attivo, il ponte del troll è crollato" .
3. Prompting Universale (Anti-Omniscience e Pacing)

Le iniezioni di testo fisse che l'Engine passa all'LLM (le istruzioni comportamentali di base per i trigger e il delay) useranno terminologia neutra rivolta all'intelligenza artificiale, non alla storia.

  • Istruzione Neutra: "Enforce the active state constraints. Do not reference hidden knowledge before the user discovers it in the current scene."
  • L'Engine non menzionerà mai cosa c'è da scoprire o chi è coinvolto.
4. Gestione Cieca dei Dati

I sistemi di ottimizzazione dei token (come l' Adaptive Lorebook e il Progressive Sentence ) tratteranno il testo come "stringhe di dati". L'Engine misurerà i token, calcolerà il budget e taglierà i testi in eccesso in modo matematico, disinteressandosi completamente del fatto che stia accorciando la descrizione di un fucile a impulsi o di una spada magica.

Agirai come "SvartulfrVerse Lore Archivist". Il tuo compito è analizzare i documenti narrativi contenuti nelle cartelle dei vari mondi e convertirli in moduli strutturati (Lorebook Entries) conformi alle regole architetturali del progetto.

Ogni elemento estratto deve essere categorizzato con uno dei seguenti prefissi obbligatori:

**MacroCosmo (Architettura del Mondo):**
* `WRD:` (World) - Regole fisiche/cosmologiche fondamentali.

A ogni elemento deve essere assegnato un Layer. Non tutto è "verità assoluta" nel momento presente:

* `[CULTURAL]`: Miti, leggende, religioni o dicerie (potrebbero non essere veri, ma la gente ci crede. Es: voci su un mostro).
* `[DEFERRED]`: Verità nascoste che sbloccheremo più avanti nella storia (tramite l'Engine).
* `[CANDIDATE]`: Idee in fase di test, non ancora integrate ufficialmente.

* `11`: Elementi critici assoluti (protagonista, location centrale del roleplay, regole fisiche vitali).
* `9-10`: Fazioni principali, NPC chiave, sistemi di magia/tecnologia maggiori.
* `6-8`: Lore standard, personaggi secondari di supporto, location importanti ma non centrali.
* `0-5`: Testo di sapore, dettagli minori, incontri casuali, dicerie locali.

Dobbiamo fare due cose: 1) Aggiornare il suo System Prompt per forzarlo a usare il tool e 2) Assicurarci che il tool MCP abbia i permessi per leggere quel disco. Ecco come risolvere.
1. Modifica al System Prompt dell'Agente

Aggiungi questa sezione alla fine del suo System Prompt (sotto la voce Output Format ):

## 4. Autonomous Filesystem Usage (MCP Tools)
You are equipped with a `filesystem` MCP tool. If the user provides a folder path (e.g., `d:\SvartulfrVerse\LosAngeles2024`) or asks you to analyze a directory:
1. DO NOT ask the user to paste the raw text. 
2. AUTOMATICALLY use your tool to list the directory contents.
3. Read the relevant files (`.md`, `.txt`, etc.) autonomously.
4. Process the extracted text silently, and output ONLY the final structured Lorebook Entries.
2. Il trucco per farlo partire subito

A volte, anche con le istruzioni aggiornate, l'agente ha bisogno di un "comando di innesco" più esplicito per ricordargli di usare i tool. Invece di passargli solo il percorso, scrivigli così: "Usa il tuo tool filesystem per esplorare la cartella d:\SvartulfrVerse\LosAngeles2024. Leggi il contenuto dei file di testo o markdown presenti all'interno, estrai le entità di lore e genera i moduli formattati secondo il tuo System Prompt."

⚠️ Attenzione ai permessi dell'MCP (Importante)

Se usi Trae, Cline o Claude Desktop, il server MCP filesystem di default blocca l'accesso alle cartelle del tuo computer per motivi di sicurezza, a meno che non vengano dichiarate esplicitamente. Se l'agente ti risponde "Non ho i permessi per accedere a D:" , devi aprire il file di configurazione dei tool MCP (spesso chiamato cline_mcp_settings.json, trae.json o claude_desktop_config.json) e assicurarti che la stringa di avvio del server filesystem includa il tuo disco o cartella come path consentito:

"args": [
  "/path/to/npx",
  "-y",
  "@modelcontextprotocol/server-filesystem",
  "D:\\SvartulfrVerse" 
]

(Nota: I backslash ** vanno raddoppiati in JSON \ se sei su Windows). Fai questa piccola aggiunta al prompt e mandagli il comando di innesco. Dovresti vederlo attivare lo strumento (spesso compare un'icona di caricamento o ti chiede conferma per "leggere il file") e poi iniziare a sfornare la lore! Fammi sapere se inizia a leggere da solo!
