  • Se rileva "Arc 2" / "Halloween" -> Start Date = 31 Ottobre 2024
  • Se rileva "Arc 3" / "Casting" -> Start Date = [Data di Arc 3] (Se non trova nulla, usa il 28 Agosto 2024 come default).
