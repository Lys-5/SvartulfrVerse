1. ZenMux

ZenMux is an AI routing gateway that currently offers completely free API access to Z.ai's flagship models, with reasonable rate limits.

  • The Setup: You generate an API key on their platform and point your base URL to https://zenmux.ai/api/v1.
  • The Catch: You must specifically request the z-ai/glm-5.2-free or z-ai/glm-4.7-flash-free model strings to avoid hitting a paywall. Because it uses the OpenAI standard, it's a seamless drop-in for Node environments or standard proxy setups.
2. Puter.js

If you are building client-side web apps and want to bypass backend server architecture entirely, Puter offers free, unlimited access to the entire GLM-5 family.

  • The Setup: You include the Puter.js script in your frontend. It operates on a "User-Pays" model, meaning the end-user authenticates to cover their own usage (which falls under the free tier for GLM).
  • The Catch: It requires users to have a Puter account to interact with the AI features in your app.
3. OpenRouter

OpenRouter maintains a permanent free tier for Z.ai's highly optimized, lightweight models.

  • The Setup: Point your API client to OpenRouter and request z-ai/glm-4.5-air:free.
  • The Catch: While it doesn't have the 1M token context of GLM-5.2, it still supports a 131K window — more than enough for standard character state tracking and prompt processing. Gemini : Puter.js è essenzialmente un SDK che ti permette di creare applicazioni full-stack scrivendo esclusivamente codice frontend. Per chi sviluppa interfacce (in Vue, React o vanilla TypeScript), elimina completamente la necessità di configurare un server backend Node.js o Python per gestire database, autenticazione o chiamate alle API dell'intelligenza artificiale. Funziona esponendo un oggetto globale puter direttamente nel browser, che funge da ponte verso l'infrastruttura cloud di Puter. Ecco come gestisce i componenti principali sotto il cofano:

1. L'Architettura "User-Centric"

Normalmente, se chiami un'API AI (come GLM o OpenAI) dal frontend, esponi la tua chiave API segreta, creando un enorme rischio di sicurezza. Puter risolve questo problema spostando l'onere sull'utente finale. Quando un utente interagisce con la tua app, si autentica tramite Puter. Qualsiasi operazione computazionalmente pesante (come generare testo con l'AI o salvare file) utilizza i limiti e le risorse gratuite dell'utente stesso, non le tue. Tu scrivi solo l'interfaccia; l'infrastruttura si scala da sola senza farti pagare il conto.

2. Come si usa nel codice

Una volta incluso lo script (), hai accesso immediato a vari micro-servizi integrati che gestiscono logiche complesse con una singola riga di codice ES6: Chiamate AI: Invece di configurare endpoint proxy e fetch request complesse, chiami direttamente il metodo AI.

// Genera una risposta usando il modello di default (o specificando GLM/OpenAI)
const response = await puter.ai.chat("Spiega cos'è un paradosso temporale");
console.log(response.message.content);

Storage (Key-Value e File System): Puoi salvare lo stato dell'applicazione, come i salvataggi di una sessione di roleplay o le impostazioni utente, direttamente nel cloud di Puter.

// Salva un dato strutturato
await puter.kv.set("user_preferences", { theme: "dark", autoreply: true });

// Recupera il dato
const prefs = await puter.kv.get("user_preferences");

Hosting istantaneo: Puter offre anche un ambiente per hostare l'app. Puoi creare un file HTML/JS e usare puter.hosting.create() per metterlo online e ottenere un URL pubblico in pochi secondi, il che è perfetto per prototipare rapidamente componenti UI o logiche sandbox e testarle live.
