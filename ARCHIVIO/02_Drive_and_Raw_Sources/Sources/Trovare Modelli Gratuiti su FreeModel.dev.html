User : FreeModel.dev dove trovare lista modelli disponibili Gemini : Per consultare la lista aggiornata dei modelli disponibili su FreeModel.dev (o servizi/API router correlati come OpenRouter o i repository di modelli gratuiti), hai principalmente tre strade a seconda che tu ne abbia bisogno via browser, da codice o via terminale:

1. Dalla Dashboard Web

Il modo più immediato per esplorare l'elenco con filtri su limiti di utilizzo, dimensioni e modalità (testo, visione, audio) è accedere direttamente al portale:

  • Sito Web: Vai su freemodel.dev (o openrouter.ai/models?max_price=0 se utilizzi la libreria/API di instradamento OpenRouter).
  • Filtro Free: Nella barra di ricerca della dashboard o nei filtri sulla sinistra, seleziona la spunta "Free" / "Price: $0" per isolare solo gli endpoint a costo zero.

2. Via API / Endpoints (Per Sviluppatori)

Se stai configurando uno script o un'applicazione (es. via Python o cURL) e vuoi recuperare l'elenco programmaticamente dei modelli disponibili in tempo reale, puoi interrogare direttamente l'endpoint /models compatibile con le specifiche OpenAI:

curl https://openrouter.ai/api/v1/models

Oppure in Python :

import requests

response = requests.get("https://openrouter.ai/api/v1/models")
models = response.json()["data"]

# Filtra solo i modelli gratuiti
free_models = [
    m["id"] for m in models 
    if m.get("pricing", {}).get("prompt") == "0"
]

print("Modelli gratuiti disponibili:")
for model in free_models:
    print(f"- {model}")

3. GitHub & Repository Community

Se cerchi un tracciamento giornaliero e una panoramica dettagliata sui limiti di rate (rate limits), contesti massimi e provider, la community mantiene elenchi auto-aggiornati:

  • GitHub Tracker: Repository come ClawLabsAI/free-ai-models su GitHub aggiornano quotidianamente la tabella di tutti i modelli LLM e Vision ad accesso gratuito (tra cui i vari Gemini, Llama, Qwen, Nemotron, Mistral ).
