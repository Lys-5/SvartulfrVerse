User : Come far girare in locale I modelli Nvidia nim Gemini : Far girare in locale i modelli NVIDIA NIM (NVIDIA Inference Microservices) è un'ottima soluzione per sfruttare l'accelerazione hardware ottimizzata (come TensorRT e Triton) tramite un'infrastruttura containerizzata pronta all'uso. Ecco la procedura completa per configurare e avviare un modello NIM sulla tua macchina.

1. Prerequisiti

Hardware:

  • Una GPU NVIDIA recente (architettura Ampere, Ada Lovelace o Hopper, es. serie RTX 3000/4000 o schede data center).
  • VRAM sufficiente per il modello scelto (es. almeno 8-12 GB per modelli base da 7B/8B parametri). Software:
  • Sistema operativo Linux (Ubuntu raccomandato) o Windows con WSL2.
  • Driver NVIDIA aggiornati.
  • Docker installato.
  • NVIDIA Container Toolkit configurato (è fondamentale per permettere a Docker di accedere alla GPU).
2. Configurazione dell'account e delle chiavi

I container NIM sono distribuiti tramite il registro NGC (NVIDIA GPU Cloud) e richiedono autenticazione.

  1. Vai su build.nvidia.com o sul portale NGC e crea un account gratuito.
  2. Genera una NGC API Key dalle impostazioni del tuo profilo.
  3. Esporta la chiave come variabile d'ambiente nel tuo terminale per comodità:
export NGC_API_KEY="inserisci_qui_la_tua_api_key"
3. Autenticazione e avvio del Container

Una volta configurato l'ambiente, devi effettuare il login al registro Docker di NVIDIA e scaricare il container del modello che ti interessa. Passo 1: Autenticazione in Docker

echo "$NGC_API_KEY" | docker login nvcr.io --username '$oauthtoken' --password-stdin

> Nota: lo username da inserire è letteralmente la stringa $oauthtoken , non il nome del tuo account. Passo 2: Avvio del modello (Esempio con Meta Llama-3-8B-Instruct) Al primo avvio, Docker scaricherà l'immagine del container (alcuni GB) e, successivamente, il sistema scaricherà i pesi del modello.

docker run -it --rm --name=nim-llama3 \
  --gpus all \
  --shm-size=16GB \
  -e NGC_API_KEY=$NGC_API_KEY \
  -v "$HOME/.cache/nim:/opt/nim/cache" \
  -p 8000:8000 \
  nvcr.io/nim/meta/llama3-8b-instruct:latest

Analisi dei flag utilizzati:

  • --gpus all: Assegna tutte le GPU disponibili al container.
  • --shm-size=16GB: Alloca memoria condivisa sufficiente, cruciale per le performance di inferenza.
  • -v "$HOME/.cache/nim:/opt/nim/cache": Mappa un volume locale per la cache. Questo evita di dover riscaricare i pesi del modello a ogni riavvio del container.
  • -p 8000:8000: Mappa la porta API esposta dal container sulla porta 8000 del tuo host locale.
4. Testare le API

I container NVIDIA NIM espongono nativamente un'interfaccia compatibile con le API di OpenAI . Questo li rende estremamente facili da integrare in frontend web, script Python o software preesistenti semplicemente cambiando l'URL di base. Attendi che il terminale confermi che il server Uvicorn è in ascolto (solitamente su 0.0.0.0:8000), poi esegui una richiesta di test da un'altra finestra del terminale:

curl -X 'POST' \
  'http://localhost:8000/v1/chat/completions' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
  "model": "meta/llama3-8b-instruct",
  "messages": [
    {
      "role": "user",
      "content": "Ciao, puoi spiegarmi brevemente cos è una API?"
    }
  ],
  "max_tokens": 150,
  "temperature": 0.7
}'

Se ricevi un JSON formattato con la risposta generata dal modello, il tuo ambiente NIM è configurato e operativo in locale.
