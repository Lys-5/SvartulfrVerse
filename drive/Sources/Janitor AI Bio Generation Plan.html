Aggiunta del Template per la Bio di Janitor AI al Flusso di Esportazione

Questo piano descrive come integrare la generazione automatica di una pagina Bio HTML per Janitor AI all'interno della pipeline di World-Forge, partendo dall'esempio fornito per il SvartulfrVerse e seguendo le linee guida del "Storefront Window".

Obiettivo

Generare automaticamente un file HTML (es. [NomeBot]_JanitorAI_Bio.html) nella cartella Export/ che funga da "Vetrina" (Storefront) per il bot su Janitor AI. La pagina dovrà catturare l'attenzione con immagini e testi d'impatto, includendo il roster, le avvertenze e una struttura di marketing ben definita.

1. Scelta dell'Approccio: Voto per l'Opzione 2 (Mista)

L'approccio ibrido (LLM per il testo + Script Python per l'HTML) è oggettivamente la strada migliore per una pipeline di sviluppo solida.

  • Separazione tra Contenuto e Presentazione: Lasciando all'Architect il solo compito di generare un output strutturato (es. un JSON con chiavi come hook, impact_line, blurb), gli permetti di concentrarsi interamente sul copywriting creativo. Potrà focalizzarsi sul trasmettere l'atmosfera del tuo mondo — ad esempio, creare un "teaser" accattivante sul delicato equilibrio di una società composta al 35% da umani, dove lupi mannari e vampiri sono le fazioni soprannaturali dominanti — senza disperdere "ragionamento" sulla formattazione.
  • Zero rotture del codice: Gli LLM tendono a dimenticare di chiudere i tag
    o a sbagliare l'annidamento delle classi CSS quando scrivono lunghi blocchi HTML. Uno script Python (magari usando Jinja2 o un semplice .replace()) che inietta il testo in un Janitor_Bio_Template.html fisso ti garantisce che la Vetrina esca sempre sintatticamente perfetta.
  • Scalabilità: Se domani decidi di cambiare il design della Vetrina (magari per adattarla anche a Lorebary o ad altre piattaforme), ti basterà modificare un file HTML senza dover fare prompt engineering da capo.

2. Gestione delle Immagini: Segnaposto (Placeholders)

Sì, l'uso dei segnaposto è la scelta più intelligente e pratica. Visto l'alto livello di dettaglio visivo che ricerchi per i tuoi personaggi (come i test iterativi per ottenere il corretto posizionamento di code e orecchie kemonomimi nello stile da lupo), la generazione visiva ha i suoi tempi e non deve bloccare la generazione del testo. Ti consiglio di strutturare il template HTML in questo modo:

<!-- Nel tuo templates/Janitor_Bio_Template.html -->
<img src="{{MAIN_IMAGE_1_1}}" alt="Main Portrait" class="storefront-main-img">

Durante la Fase 4, lo script Python sostituirà i tag temporanei con URL visivi temporanei ma espliciti (es. https://placehold.co/500x500/1a1a1a/e0e0e0?text=Main+Portrait). In questo modo, quando aprirai il file HTML generato per fare la tua Verification Manuale , vedrai visivamente gli spazi vuoti pronti. Ti basterà poi incollare i link definitivi (da Imgur o Discord) prima di copiare il tutto su Janitor AI.

2. Inserimento nel Template HTML

Nello script Python e nel file Janitor_Bio_Template.html, possiamo iniettare questi prompt usando i commenti HTML . I commenti HTML non sono visibili quando guardi la pagina formattata e vengono ignorati dalle piattaforme come Janitor AI, ma tu potrai leggerli e copiarli semplicemente aprendo il file generato in qualsiasi editor di testo (o guardando il codice sorgente).

<!-- ========================================== -->
<!-- 🎨 PROMPT GENERAZIONE MAIN PORTRAIT (1:1): -->
<!-- {{MAIN_PORTRAIT_PROMPT}}                   -->
<!-- ========================================== -->
<img src="{{MAIN_PORTRAIT_URL}}" alt="Main Portrait" class="storefront-main-img">

<!-- ========================================== -->
<!-- 🎨 PROMPT GENERAZIONE BANNER (16:9):       -->
<!-- {{BANNER_PROMPT}}                          -->
<!-- ========================================== -->
<img src="{{BANNER_URL}}" alt="Supporting Banner" class="storefront-banner">
I Vantaggi di questo approccio:
  1. Flusso ininterrotto: Apri il file generato, leggi il commento HTML, copi il prompt, generi l'immagine, prendi il link finale e sostituisci il placeholder {{MAIN_PORTRAIT_URL}}.
  2. Coerenza visiva: L'Architect può variare il prompt in base al personaggio (es. specificando dettagli per i vampiri e dettagli diversi per i licantropi, garantendo che le caratteristiche anatomiche siano rispettate).
  3. Nessun impatto sull'utente finale: Chi legge la bio su Janitor AI non vedrà mai questi prompt, nemmeno per sbaglio. Sei d'accordo con questa struttura per inserire i prompt visivi?
