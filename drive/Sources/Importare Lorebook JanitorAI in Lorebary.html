Lorebary (l'estensione proxy non ufficiale creata da Sophia) non è in grado di leggere nativamente i file esportati da JanitorAI, perché si aspetta i dati scritti e formattati a modo suo. 1. Inserimento Manuale (Il metodo più sicuro)

Poiché Lorebary ha un suo portale specifico per la creazione dei lorebook, il modo più affidabile per importarli è copiarli manualmente:

  1. Apri il tuo file JSON di JanitorAI usando un semplice editor di testo (come Blocco Note su Windows o TextEdit su Mac).
  2. Individua le parti testuali (le descrizioni dei personaggi, dei luoghi, ecc.).
  3. Vai sul sito web del portale di Lorebary.
  4. Crea le tue entry manualmente copiando e incollando i testi. Nota: La documentazione di Lorebary consiglia spesso di racchiudere le entry in tag simili all'XML per aiutare l'AI a comprenderle meglio (ad esempio: <nome_luogo>inserisci le informazioni qui</nome_luogo>).
2. Conversione con l'aiuto dell'AI (Metodo rapido)

Se il tuo lorebook di JanitorAI è lunghissimo e non vuoi fare tutto a mano, puoi far tradurre il codice a un LLM (come me).

3. Ripulitura del JSON

  1. Crea un lorebook "vuoto" di prova direttamente su Lorebary (con solo una voce di test) ed esportalo.
  2. Apri sia il JSON di Lorebary che quello di JanitorAI.
  3. Confronta le voci. Probabilmente noterai che i nomi delle variabili cambiano (es. entries contro world_info, o keyword contro keys). Dovrai rinominare i campi del tuo file JanitorAI per farli combaciare con quelli di Lorebary.   • position: 1

  • macro: false
  • matchWholeWords: true
  • caseSensitive: false
  • extensions: {} (empty object) Requirements: The script should use standard libraries only. It should allow me to specify an input file (e.g., janitor_lore.json) and save the result to a new file (e.g., lorebary_lore.json) with proper indentation.
